
# Personal Portfolio Website 🚀

A modern, responsive dark-themed personal portfolio website built to present academic background, technical skills, software engineering projects, certifications, and contact details.

🌐 **Live Demo:** [saad-portfolio-ck28.vercel.app](https://saad-portfolio-ck28.vercel.app/)  
📂 **Repository:** [GitHub Repository](https://github.com/saadpervaiz07-coder/Arch_Technologies/tree/main/ArchTechnologies_WebDev_1month/Portfolio)

---

## 📌 Features

- **Hero & About Section:** Introduces academic focus in Software Engineering at the University of Karachi.
- **Academic Background:** Detailed timeline covering matriculation, intermediate, and ongoing undergraduate degree.
- **Technical Toolkit:** Categorized breakdown of programming languages, web technologies, backend/systems tools, databases, concepts, and developer workflows.
- **Projects Showcase:** Clean grid displaying web, systems, C++, and Java applications.
- **Certifications & Learning:** Highlights certifications in Agentic AI, LLMs, Transformer architectures, and Cybersecurity.
- **Events & Participation:** Showcases active involvement in tech conferences and community builder groups.
- **Responsive Layout:** Optimized for smooth navigation across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Styling:** Custom CSS with CSS Variables, Flexbox, and Grid
- **Deployment:** Vercel
